# VITYARTHI – Employee Payroll Management System Documentation

This folder contains the supporting documentation for the Python Employee Payroll Management System.

## Contents
- `flowcharts/overall_flowchart.png` – complete user/program flow
- `flowcharts/validation_flowchart.png` – employee ID and experience validation
- `flowcharts/salary_calculation_flowchart.png` – bonus and final salary logic
- `diagrams/module_architecture.png` – module-level architecture
- `screenshots/sample_execution.png` – sample console execution
- `screenshots/sample_execution.txt` – text form of the sample execution
- `PROJECT_DOCUMENTATION.md` – detailed project documentation

## Running the project
Run the modular entry script:

```bash
python input.py
```

The program requests employee information, validates the employee ID and experience, determines a basic salary from the selected tier, calculates the experience-based bonus, and displays the final salary.
